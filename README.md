# HR ANALYTICS DASHBOARD(Interactive HR Analytics Dashboard created using Microsoft Excel)

# Project Objectives
- Analyze employee workforce data and HR performance.
- Monitor key HR KPIs such as employees, active employees, and leavers.
- Compare employee headcount across departments and locations.
- Analyze employee gender distribution.
- Understand salary and employee tenure patterns.
- Analyze workforce trends based on hire date and age.
- Support HR decision-making through interactive data visualization.

 # Dataset Used
 <a href="https://github.com/sravanthi287/HR-ANALYTICS-DASHBOARD/blob/main/HR%20ANALYTICS%20DASHBOARD.xlsx">Dataset</a>

 # Questions (KPIs)
- What is the total number of employees?
- How many employees are currently active?
- How many employees have left?
- What is the average salary?
- What is the average employee tenure?
- What is the average employee age?
- What is the average training value?
- Which department has the highest headcount?
- How is the workforce distributed by gender?
- Which locations have the highest headcount?
- How does salary vary across locations?
- How has employee hiring changed over the years?

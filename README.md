# HR ANALYTICS DASHBOARD(Interactive HR Analytics Dashboard created using Microsoft Excel)

# Project Objectives
- Analyze employee workforce data and HR performance.
- Monitor key HR KPIs such as employees, active employees, and leavers.
- Compare employee headcount across departments and locations.
- Analyze employee gender distribution.
- Understand salary and employee tenure patterns.
- Analyze workforce trends based on hire date and age.
- Support HR decision-making through interactive data visualization.
